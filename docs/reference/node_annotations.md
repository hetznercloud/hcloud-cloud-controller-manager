# Node Annotations

This page contains all annotations, which can be specified at a Node object.

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `instance.hetzner.cloud/robot-external-ipv6` | `string` | `-` | Configures the IPv6 address a Robot server is reachable at. We use it as the IPv6 ExternalIP of the Node instead of deriving one. |
