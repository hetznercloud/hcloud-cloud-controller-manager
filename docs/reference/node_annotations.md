# Node Annotations

This page contains all annotations, which can be specified at a Node object.

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `instance.hetzner.cloud/external-ipv6` | `string` | `-` | Configures the IPv6 ExternalIP of the Node, instead of deriving it from the IPv6 subnet the server reports. This annotations can be set for Cloud and Robot servers. |
